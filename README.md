# IOTEK

A modern, premium operations dashboard for IoT systems and infrastructure monitoring.

## Features
- High-contrast dark dashboard interface
- Device monitoring and review panels
- Live system metrics with percentages
- Performance cards and alert tracking
- Responsive layout for desktop and tablet views

## Tech stack
- React
- Vite
- CSS custom properties
- React Icons

## Run locally
1. Install dependencies:
   npm install
2. Start the development server:
   npm run dev
3. Open the app in the browser at:
   http://localhost:5173

## Production build
npm run build
