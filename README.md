# IOTEK

Advanced enterprise security dashboard inspired by modern network operations portals.

## Overview
This repository contains a polished dark-mode interface for an operational security and network monitoring platform.

## Included
- Enterprise dashboard layout
- Sidebar navigation
- KPI metric cards
- Network traffic chart
- Security posture donut
- Device status table
- Recent events panel
- Responsive design for desktop and mobile

## Run locally
Open `index.html` directly in a browser, or serve the folder with a simple local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
